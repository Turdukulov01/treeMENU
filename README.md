# Django Tree Menu

Django-app, реализующий древовидное меню с настройкой через админку и выводом через template tag.

## Возможности

- Хранение структур меню и пунктов в БД.
- Редактирование через стандартную Django-админку.
- Вывод меню через template tag:  
  `{% draw_menu 'main_menu' %}`.
- Активный пункт определяется по текущему URL.
- Всё, что над активным пунктом, раскрыто; первый уровень детей под активным тоже раскрыт.
- На одной странице можно выводить несколько разных меню (по названию).
- URL пункта может задаваться:
  - явным образом (`/contacts/`),
  - через named url (`'contacts:list'`).
- На отрисовку КАЖДОГО меню уходит ровно **один** запрос к БД.
